Support

Use this page for help with BabySounds during beta testing and release preparation.

During TestFlight

The best way to report a beta issue is through the TestFlight app. Open TestFlight, choose BabySounds, then send feedback with a short description and screenshot if helpful.

Common checks

  • If playback stops, confirm the device is not muted and volume is above zero.
  • If background playback stops, reopen BabySounds and start the sound again.
  • If widgets do not update, open the main app once, then return to the Home Screen widget.
  • If premium access is missing after purchase, use Restore Purchases in Settings.

Contact

A public support email will be added before App Store release. For now, TestFlight feedback is the primary beta support channel.
